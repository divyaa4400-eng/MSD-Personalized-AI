# Data Availability

The default experiments in this repository use a fully synthetic multimodal cohort generated programmatically by `src/synthetic_data.py` from documented configuration values and random seeds.

No patient-level clinical dataset, identifiable patient information, protected health information, hospital record, or human tissue dataset is distributed with this repository.

The complete synthetic cohort can be regenerated by running:

```bash
python run_full_pipeline.py --config configs/default.yaml
```

The generator creates MRI-like, CT-like, and X-ray-like image surrogates together with clinical, demographic, and biomechanical variables and the corresponding synthetic risk targets. The configuration and split manifest are stored alongside the run outputs to support exact computational traceability.

If actual clinical data are introduced in a later study, this statement must be replaced by the genuine data-governance and access conditions for those data.
